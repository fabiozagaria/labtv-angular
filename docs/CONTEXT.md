# Contesto tecnico — LabTV

Aggiornato: 2026-09-08

## Stato
Release frontend 1.0.0 completata rispetto allo scope dichiarato. Il progetto non è attualmente in sviluppo attivo.

## Stack e capacità presenti
- Angular 21 e TypeScript 5.9;
- RxJS, Signals, Router e HttpClient;
- integrazione TMDB per catalogo, ricerca, dettaglio, cast, regista e titoli simili.

## Limiti dichiarati
- frontend only;
- login dimostrativo, senza autenticazione reale;
- nessuna persistenza utente.

## Punto di ripresa
Nessun passo attivo. Un backend, profili o persistenza devono essere trattati come una nuova evoluzione LabTV 2.x, non come correzioni mancanti della 1.0.0.
